Mood animations for the Home and EMIs screens.

Drop one Lottie file per mood here, named exactly:

  great.json      spending well within what is safe / all EMIs up to date
  happy.json      on track
  careful.json    spending too fast, or EMIs heavy
  worried.json    something overdue, or about to run short
  thinking.json   nothing entered yet

.lottie files work too (great.lottie, ...). Any mood without a file shows a plain face instead.
Use animations whose licence allows use in a commercial app.
